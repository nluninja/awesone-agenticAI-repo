# Contributing to Awesome Agentic AI

Thank you for your interest in contributing! This guide will help you add valuable resources to the list.

## Guidelines

### General Rules

- Search previous suggestions before making a new one to avoid duplicates
- Make an individual pull request for each suggestion
- Use the following format: `[Resource Name](link) - Brief description`
- Keep descriptions short, clear, and informative
- New categories or improvements to the existing categorization are welcome
- Check your spelling and grammar
- Make sure your text editor is set to remove trailing whitespace

### Quality Standards

Resources should be:

- **Relevant**: Directly related to agentic AI, autonomous agents, or AI agent frameworks
- **High Quality**: Well-documented, maintained, or peer-reviewed
- **Accessible**: Publicly available (papers, open-source projects, free resources)
- **Current**: Recently published or actively maintained (exceptions for foundational works)

### Adding Different Types of Resources

#### Papers

- Include full citation with authors and year
- Prefer arxiv.org links for accessibility
- Include both foundational and recent papers
- Add brief description of the paper's contribution

Example:
```markdown
- [ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629) - Yao et al., 2022 - Introduces method combining reasoning traces with task-specific actions
```

#### Frameworks & Tools

- Must be open-source or have a free tier
- Include GitHub stars if applicable (for credibility)
- Actively maintained (updated within last 6 months preferred)
- Clear documentation

Example:
```markdown
- [LangChain](https://github.com/langchain-ai/langchain) - Framework for developing applications powered by language models with agent capabilities
```

#### Videos & Courses

- Must be publicly accessible (free or with clear pricing)
- Include creator/platform name
- Preference for high-quality educational content
- Include difficulty level if relevant (beginner/intermediate/advanced)

Example:
```markdown
- [Building AI Agents - DeepLearning.AI](https://www.deeplearning.ai/short-courses/) - Comprehensive course on agent development (Intermediate)
```

#### Legal Resources

Legal resources are particularly important for this list. Include:

- Official regulatory documents
- Academic papers on AI law and policy
- Industry guidelines and standards
- Case studies and precedents
- Multi-jurisdictional perspectives

Example:
```markdown
- [EU AI Act - Official Text](https://artificialintelligenceact.eu/) - Comprehensive EU regulation on AI systems with specific provisions for autonomous agents
```

## Pull Request Process

1. Fork the repository
2. Create a new branch (`git checkout -b add-resource-name`)
3. Add your changes to README.md
4. Commit with a descriptive message (`git commit -m "Add [Resource Name] to [Category]"`)
5. Push to your fork (`git push origin add-resource-name`)
6. Open a Pull Request with:
   - Clear title describing what you're adding
   - Brief explanation of why the resource is valuable
   - Confirmation that you've checked for duplicates

## Reporting Issues

- Use GitHub Issues for:
  - Broken links
  - Outdated resources
  - Suggestions for new categories
  - General improvements

## Code of Conduct

- Be respectful and constructive
- Welcome newcomers and help them contribute
- Focus on what is best for the community
- Show empathy towards other community members

## Questions?

Feel free to open an issue for any questions about contributing!

Thank you for helping make this resource valuable for the agentic AI community!
